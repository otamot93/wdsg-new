## B 日循环骨架（主干）

偏 CK3 的**暂停循环**，砍通视；**不**采用三国志 14 式每日早朝刷奏折为主干。

```
设常驻方针 → 时间慢走（挂机）→ 消息流只推异常 / 到期回报
        ↑                                         │
        │                    点开异常 → 可选暂停、可读、可下令
        │                                         │
        └──────── 危机触发 → 强制暂停 → 已知范围内选目标确认 ─┘
```

### 1. 常驻方针（议会挂机）

- 玩家设「常驻方针」后，时间可推进；部下按方针自动干活（例：稳边 / 积粮 / 盯某邻）。
- **非**每帧点州下令；地图不是每天第一站，是证据板。
- 方针必须可感、可改；世界（NPC / 压力规则）会把方针读成主公态度（对齐 Pillar「没有中立按钮」精神）。
- **方针切换摩擦：轻**——换了很快生效，短时间有一点点换档别扭；不设长硬冷却。
- **主动动作不设额度限制**：暂停/读消息本来就不计；主动下令、情报采购、换方针也不限额（仍不鼓励天天点兵刷图，靠摩擦与成本，不靠额度）。
- **玩家可随时自愿暂停**挂机或日推进；自愿停与危机强制停是两回事。

### 2. 异常消息流（打断注意，非看图优先）

- 平时：消息流**只推异常**与到期阴谋 / 探子回报；常规流水不刷屏。
- 点开消息 → 才进入注意 / 可选暂停；不强制「先看图再读流」。
- 卡仍带来源 + 日戳 + 主张；UI 不代判真伪、不给可信度分、不建议「先打谁」。

### 3. 危机强制暂停

- 危机例：敌军出现在**已知区**、城失联、阴谋暴露等 → **强制暂停**挂机。
- **危机强制停本身不可关**；普通提示可关；触发时**须说明理由**；玩家**可选继续挂机**。
- 玩家处理危机时只能在**已知情报范围内**选目标并确认下令。
- 已知区须达**精确门槛**才强制停；迷雾外仅弱信号（不直接当精确警报）。
- 脏情报可制造假危机或掩盖真危机（仍走可见卡，不泄 Hidden）。

### 4. 下令通道（零件保留，非日默认骨架）

- 下令形态仍可保留：地图选目标 → 确认（摘要只用当前可知信息）。
- 首版地图令：出征、调防（与壳方向一致）。
- 未知邻境仍允许下令（迷雾不是门禁）；失败短句只说玩家能理解的原因。
- **唯一下令通道等可保留为交互零件，但不再是「每天默认骨架」。**

## 与旧四步对照（作废说明）

| 旧四步（已作废） | 本版 B |
|------------------|--------|
| 看图 → 读流 → 点卡下令 → 等回声 | 设方针挂机 → 异常流注意 → 危机强制暂停 →（可选）已知范围下令 |
| **看图优先**为日循环默认入口 | 地图降为证据板；**不作每天第一站** |
| 每天默认走完「点卡下令」环 | 危机外少精确军情；主动令**不设额度**（已拍板） |
| 读流为日常主干节奏 | 流只推异常 / 到期回报；点开才暂停 |

**结论**：旧「看图优先」日循环骨架**整段作废**。选目标→确认等零件可留，但不得再写成「每天默认四步」。

## 迷雾红线（认知迷雾）

口号沿用：`壳可以更像 CK3，知情权必须反 CK3。`

| 红线 | 要求 |
|------|------|
| 迷雾外无精确警报 | 不可见区域**不得**给精确定位 / 兵力 / 真相等警报 |
| 最多模糊信号 | 例：「某方向久无信」；禁止「敌军正在围 X」类精确卡（当 X 对玩家不可见） |
| 邻境 | 仅「据 Day X · 来源」快照或「未知」；禁止 Hidden 真值进 UI |
| 治下 | 钱粮兵等可按 Pillar 显示真值（自家库房，非雾化对象） |
| 确认摘要 | 只用当前可知信息；不补全未知邻境 |
| 禁项 | 可信度分/条、`truth_refs`、代判建议、无来源局势播报 |

开发盯风险（摘自玩法文档）：自动化过强 → 玩家觉得没决定（方针要可感可改）；别滑回「盯地图点部队」。

## 给主程 / UI / 叙事的接口暗示（高层面，无代码）

### 主程 / 服务端

- 世界时钟：支持「慢走 / 挂机」与「危机强制暂停」两态；另支持玩家**随时自愿暂停**。危机强制停**本身不可关**；普通提示可关；须说明理由；可选继续挂机。
- 方针：存玩家当前常驻方针；规则层按方针驱动部下自动行为；方针变更计入政治信号（可被 NPC 读取）。
- 消息投递：区分「异常 / 到期回报」与常规；危机类消息触发强制暂停钩子。
- 警报过滤：生成警报前过「玩家可知」门禁——迷雾外只允许模糊信号。
- 下令：仍走选目标→确认→规则结算→DelayQueue 回声；主动情报采购 / 换方针 / 下令**不设额度**（靠钱、延迟、轻摩擦约束）。

### UI

- 默认壳仍是：地图司令部 + 侧边情报消息流（不要案头）。
- 挂机态：时间推进可见；方针条 / 状态可感；异常角标涨，不强制抢图。
- 危机态：强制模态或等价打断；只能在已知范围内点选目标。
- 确认窗：可知摘要三源精神不变（治下真值 / 邻境快照 / 己方可派）；不读 Hidden。

### 叙事

- 危机与异常文案带来源、日戳、立场；禁系统日志腔与「其实真相是」。
- 假危机 / 掩盖真危机：靠脏情报卡，不靠编剧日历（D7 涌现仍有效）。
- 方针被世界读成态度：可用回声 / 沉默体现，不写 DayN 必发剧本。

## 开放项（仅实现细节；不再有拍板题）

日循环方案 **B 已拍板**。下列仅落地时定，不再回问「要不要 B / A / C」：
