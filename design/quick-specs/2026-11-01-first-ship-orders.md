# Quick Design Spec: 首版命令集

**Type**: 玩法设计 / 命令（令）系统
**Date**: 2026-11-01
**Status**: **拍板（2026-11-01）**；服从 `docs/游戏玩法.md` 与日循环 B；不开 feature、零改 Godot
**起因**：玩法 review 发现首版只有「出征 / 调防」，回应不了 908 的主压力（李克宁政变、后梁诱降、将帅不睦）。

---

## 0. 设计目标

1. 908 开局三大压力，每条至少有 **2 种以上**可下的令去应对，且彼此有取舍。
2. 每道令都答得出五问（派了谁 / 要多久 / 花了什么 / 谁会怎么读 / 暴露了什么），**不设额度**。
3. 命令本身也要服从迷雾：下令时不知道结果，回声只进消息流。
4. 令要少而能组合，不做 CK3 式几十个按钮。首版 **12 道 P0 + 3 道 P1**。

---

## 1. 通用规则（所有令共用）

### 1.1 令的语法

```
动词 + 目标 + 执行人 (+ 参数) → 确认摘要（五问）→ 驿传在途 → 执行 → 回声进消息流
```

### 1.2 目标类型

| 目标类型 | 可选范围 | 禁止 |
|----------|----------|------|
| **地点**（州 / 关） | 任意州，含未探明州（迷雾不是门禁） | — |
| **己方人物** | 名册中任意己方人物 | — |
| **外部人物** | 已在消息流中出现过的（「已闻其人」）；首版仅用于派探 | 从未出现在情报里的人物 |
| **集团** | 牙军/义儿军、监军/文官、边镇、地方 | — |
| **一条消息** | 消息流中的任意一条（用于查证） | — |
| ~~敌军单位~~ | — | **任何时候都不能当目标** |

军事令目标是地点，人事令目标是人物或集团。

### 1.3 执行人

- 每道令必须有执行人；**一人一事**，派出即离岗，离岗期间其原职空缺。
- **主公（李存勖）也是执行人**，见 §3。
- **驿传**：命令送达靠驿传，不占人物，只有路程延迟、可能被截或迟滞。避免「送召回令也要派人」的无限递归。
- **路程从主公所在地起算**：命令与消息共用同一套驿传；主公在哪，命令从哪发、消息往哪送。
- **召回 / 改令永远可下**（只要对方仍在己方驿传可达范围）→ 危机门槛「有得应对」恒有解。

### 1.4 确认摘要

- 只用当前可知信息回答五问。
- 「谁会怎么读」**只列知情范围**（谁会知道这道令），**不预测任何 NPC 反应**、不给成功率。
- 失败或受阻时只给玩家能理解的原因（「某将托病未至」「驿路断于某关」），不给系统判定腔。

### 1.5 明令为默认；拘捕自带「密」

- 首版**不做**通用明令 / 密令开关；所有令默认为明令，相关集团都会读到。
- **拘捕例外**：下令到动手之间有一段**准备期**，准备期内有泄露风险；泄露 = 打草惊蛇，目标可能出逃、拒召或先动手。

### 1.6 受令方可以不照办

对己方人物下的令，执行人/目标可：照办、拖延、阳奉阴违、托病、拒令。
**不照办本身就是情报**——「召而不至」比任何可信度条都更能说明问题。拒令/索饷危机应主要从这里自然长出来，不靠脚本。

### 1.7 换方针不是令

方针是施政口径，由四集团代表人物在日常里执行，**不挂单一执行人**。五问中只需答：

- **要多久**：轻摩擦过渡期，旧任务收尾；
- **谁会怎么读**：切换唤醒相关 NPC 重估，被读成态度。

这是五问「答不出派了谁就不该存在」的**明文例外**。

## 2. 首版命令表

P0 = 首版必需；P1 = 首版想要，可砍。

### 2.1 军事（目标：地点）

| 令 | 目标 | 执行人 | 要多久 | 花什么 | 谁读 / 暴露 | 级 |
|----|------|--------|--------|--------|-------------|----|
| **出征** | 州 / 关 | 将领 + 所部（或主公亲征） | 路程 + 战事 | 行粮、军饷 | 后方空虚；被读成主战 | P0（已有） |
| **调防** | 己方州 | 将领 + 所部 | 路程 | 少量行粮 | 原驻地空缺；频繁调防被读成备战 | P0（已有） |
| **召回** | 己方在外人物 / 部队 | 驿传 | 驿路延迟 | 无 | 被召者及其部属读成态度（猜忌 / 收缩） | P0 |
| **输粮** | 己方州 | 将领或转运官 + 护卫 | 路程 | 粮（路上可能被截） | 粮道成为敌方目标；护卫离岗 | P0 |

> **被围城的存粮单独计算**：镇库粮再多也进不了围城，只能靠本令破围送入。908 里「积粮」方针不等于救潞州。

### 2.2 人事与内部政治（目标：己方人物 / 集团）

| 令 | 目标 | 执行人 | 要多久 | 花什么 | 谁读 / 暴露 | 级 |
|----|------|--------|--------|--------|-------------|----|
| **召见** | 己方人物 | 驿传传召 | 对方路程 | 无 | 被召者离开部曲到主公所在地；**可能托病不至**（信号） | P0 |
| **赏赐** | 人物或集团（犒军） | 文官（判官 / 掌书记） | 数日 | 钱帛、粮 | 被读成偏信；未得赏者相比较 | P0 |
| **任免** | 己方人物 + 职位（含留守） | 文官出牒；夺兵权须将领接手 | 牒到之日 | 无（或安置费） | 被免者及其集团读成打压；可能拒不交兵 → 拒令危机 | P0 |
| **拘捕** | 己方人物 | 亲军将领（目标与主公同在一地时可「宴中」） | 准备期 + 就地即时 / 遣兵往捕路程 | 亲军离岗 | 准备期可能泄露；失败 = 逼反；成功也会让同集团人自危 | P0 |
| **安抚** | 集团（多用于地方） | 文官或本地主官 | 数日至一旬 | 钱粮或许诺（许诺未兑现会反噬） | 该集团态度；其他集团读成偏袒 | P1 |

### 2.3 情报（沿用玩法文档，补齐命名）

| 令 | 目标 | 执行人 | 备注 | 级 |
|----|------|--------|------|----|
| **招募探子** | — | 文官经手 | 候选 2–4 人，可过期 | P0（已有） |
| **派探** | 州 / 方向 / 已闻人物 | 探子 | 同向重复暴露递增 | P0（已有） |
| **查证** | 一条消息 | 探子 | 结果仍是一条新消息，可再矛盾；不给「真 / 假」判定 | P0 |
| **补救**（换渠道 / 撤离 / 封口） | 已暴露探子或线路 | 探子或文官 | 局部补救，禁全局洗白 | P0（已有） |

### 2.4 内政（目标：己方州）

| 令 | 目标 | 执行人 | 花什么 | 谁读 | 级 |
|----|------|--------|--------|------|----|
| **加征** | 己方州 | 州主官 | 地方怨气上升；主官可能截留 | 地方读成盘剥；牙军读成「有饷」 | P1 |
| **开仓赈济** | 己方州 | 州主官 | 粮 | 地方读成收拢；可能被主官中饱 | P1 |

> 加征 / 赈济给钱粮第二条来源，削弱「积粮」方针成为每局唯一最优解的风险。

**合计**：P0 12 道（含已有 5 道：出征、调防、招募探子、派探、补救），P1 3 道。

### 2.5 后置（不进首版）

| 令 | 后置原因 |
|----|----------|
| **遣使**（求援 / 结好 / 回书） | 908 开局外交非主压力；契丹、岐、吴等地图外政权首版只以弱信号 / 压力规则存在，不可交互 |
| **诈降 / 反间** | 依赖「错误情报进入 NPC 认知」（tick 备忘第三阶段），随之一起做 |
| **通用明令 / 密令开关** | 需完整泄露模型；首版只有拘捕自带准备期泄露 |

## 3. 主公是执行人（本稿最重要的一条）

- 李存勖同一时间只办一件事：**坐镇 / 亲征 / 亲巡 / 设宴**。
- 主公不在治所时：
  - 「拘捕 · 宴中」只对随行或被召至主公所在地的人可用，其余只能遣兵往捕；
  - 治所由留守代管（任免一位留守 = 把后背交给谁）；
  - 命令从主公所在地起算路程：前线令快，治所与后方的令慢、消息也慢。
- 这让 908 的核心两难天然成立，而不用写剧情。

## 4. 908 两难示例（无脚本，仅说明命令如何组合）

> 潞州粮在倒数；晋阳有李克宁的流言；周德威与李嗣昭不睦。

| 玩家可能的路 | 用到的令 | 代价 / 风险 |
|-------------|----------|-------------|
| 先稳后方 | 召见李克宁 → 宴中拘捕 | 若流言是假的，杀错人寒了义儿军；准备期泄露或召而不至，计划落空 |
| 先买时间 | 犒军（赏赐牙军）+ 任免削兵权 | 耗钱；削权可能当场逼反 |
| 先救潞州 | 主公亲征 + 任命张承业留守 | 晋阳无主且消息变慢，李克宁若真有谋，正是时机 |
| 两头都派人 | 周德威出征 + 输粮潞州 | 周德威与李嗣昭不睦，前线协同可能拖延 |
| 先查清 | 查证流言、派探晋阳诸营 | 花时间；潞州在倒数；同向重复查证会暴露 |

告密者不一定存在、政变不一定发生——同一组令在不同局里结果不同。
