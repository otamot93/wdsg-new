**Type**: Direction / Simulation skeleton  
**Date**: 2026-11-01  
**Status**: **设计备忘（未拍板）**；不替换日循环 B；不开 feature；零改 Godot  
**Audience**: 主程 / 系统设计 / 叙事（规则层骨架；不写引擎实现）

| 项 | 口径 |
|----|------|
| 权威玩法 | `docs/游戏玩法.md`：一句话、目标、日循环 B、迷雾、下令、壳 |

| 本文件 | 把 **世界时钟 Tick** 与 **NPC 人物 AI** 收成可执行骨架，供模拟层对齐 |
| 冲突处理 | 与玩法文档冲突，以 `docs/游戏玩法.md` 为准，并回改本文件 |

本稿默认以下口径已经锁定，不再重选：

- 日循环 **B**：议会挂机 + 危机打断；旧四步看图优先作废。
- **壳可以更像 CK3，知情权必须反 CK3。**
- 多剧本；首剧本「河东 908」玩家为李存勖，后梁为敌对伪朝（诱降），唐名分为资源；目标是迷雾里保住镇，不是一统天下。
- 时间尺度（2026-11-01 已定）：1 倍速 1 日约 10 秒；NPC 按**旬**定期重估；月结饷。
- 主动动作不设额度；方针轻摩擦；危机强制停本身不可关。
- 界面禁止「可信度」分/条/文案；不做全局忠诚条站队。
- LLM 只可增强文案，**不得**参与每个 NPC 的日常决策，也不得改写规则。

### 一句话

> 世界按固定 Tick 自己运转；人物 AI 只在被唤醒时重算计划；玩家看到的永远是裁剪后的认知，不是 Hidden 真值。

挂机不是空转数值，而是让治下集团、邻镇军阀和朝廷按各自利益行动。危机不是随机弹窗，而是这些行动撞上玩家已知范围后结出的账单。

## 从 CK3 借什么、不借什么

只借鉴系统零件，不抄封建制假设，不抄通视。

### 可借

| CK3 零件 | 落到本作 |
|----------|----------|
| 角色驱动，而不是抽象国家 AI | 决策主体是人物及其所属集团，不是「晋国」标签 |
| 世界持续推进，关键事件才唤醒角色 | 定时扫描 + 事件唤醒；不每人每帧重算 |
| 计划分短/中/长期，不每月改主意 | 危机或结构性变化才重算长期目标 |
| 内阁/政策持续生效 | 对应玩家常驻方针；NPC 也有自己的常驻姿态 |
| 人物关系与能力改变执行质量 | 同一条令，换执行人，快慢、偏差、政治代价都不同 |

五代十国比西欧封建更碎、更短命。基本单位不要做成「国王—公爵—伯爵」，而应是：

> **高频政权更替、低稳定度的军阀政治 + 以府州和军镇为核心的行政网络 + 依赖亲军、牙军、藩镇和士人的个人权力结构。**

### 不借

- 邻国兵力 / 性格 / 关系通视。
- AI 近乎全知后再做最优解。
- 全局可见的忠诚条、好感条、可信度分。
- 所有角色每月完整思考。
- 「统一 / 称帝」作为默认胜利函数。
- 事件题库刷最优答案。
- 用 LLM 替代规则层决策。

玩家界面的红线不变：迷雾外无精确警报；确认摘要只用当前可知信息；NPC 内部评分、Hidden 意图、集团真值 **禁止** 进 UI。

## 1. 模拟对象（四层）

人物是 AI 的决策主体，但人物不是孤立行动的。

### 1.1 人物

每位进入 AI 的人物拥有：

- **性格**：勇猛、猜忌、贪婪、宽仁、果断、保守、野心、多疑、崇文等。性格不直接选战略，只改权重。
- **能力**：统军、谋略、内政、外交、识人。
- **身份**：皇帝、节度使、刺史、将领、监军、宦官、士人、宗室、豪强、牙将。
- **关系**：君臣、亲族、婚姻、旧部、宿敌、门生、盟友。关系拆维度，不合成一条「好感」。
- **资源控制**：军队、财富、粮食、城池、亲军、声望。
- **忠诚对象**：朝廷、藩镇、家族、个人恩主、地方集团——可并存、可冲突。
- **认知状态**：已知 / 推测 / 错误 / 延迟。AI **只基于自己的认知决策**，不读 Hidden 真值。

玩家本人不是 AI。玩家通过常驻方针和主动下令授权；部下按方针执行，带摩擦。

### 1.2 权力集团

五代十国区别于 CK3 的关键。许多行为应由集团利益驱动，而不是单条个人忠诚。

首版建议实体化的集团：

| 集团 | 主要要什么 | 典型动作 |
|------|------------|----------|
| 亲军 / 牙军 | 军饷、战利品、不被整编、家属安全 | 索饷、拒调、拥立、兵变 |
| 监军 / 文官 | 朝廷名义、税赋上缴、文书权 | 参奏、拖延、另报一条消息 |
| 地方豪族 | 田土、治安、少被征发 | 观望、匿粮、私通邻镇 |
| 边镇将领 | 边功、补给、不被抽走精兵 | 报急、瞒败、擅自出击 |
| 朝廷 / 外部政权（按剧本定义；908 为敌对的后梁） | 有可服从朝廷时：削藩、征贡、维持名分。908 后梁：招降、吞并河东 | 有可服从朝廷时：加官、削权、征召、另委。908 后梁：对部将/地方许官许地诱降、长围潞州 |

后置、不阻塞首版：宦官、宗室、盐铁商人、外族/边军、旧朝遗臣。

例：节度使是否称帝（后置内容，首版不当默认目标）

```text
称帝意愿
= 个人野心
+ 亲军支持
+ 地方财政自主
+ 朝廷虚弱
+ 其他藩镇态度
- 失败被讨的风险
- 名分不足
```

### 1.3 政权

政权不是地图颜色，而应有：

- 合法性 / 实际控制区 / 朝廷权威
- 财政能力 / 军事动员 / 官僚能力
- 核心军队 / 继承秩序
- 对地方的任命权是否能落地
- 对外承认度

首版玩家只直接操作河东；邻镇政权用同一套字段，但 AI 驱动。

### 1.4 地方与军镇

基础地图单元建议：

- **州 / 府**：财政、人口、粮、联络点。
- **军镇**：军事组织与控制。
- 关隘、粮道、漕运、盐场、兵源、都城——作为战略价值，不都做成可点单位。

开局种子「河东 908」约 12 州 + 潞州边压读点；首版不要按全中国规模做 AI 人数。

每个州府拆控制值（Hidden，不进 UI 条）：

```text
名义主权
行政控制
税收控制
军事控制
地方精英合作度
```

只有这些值逐步提高，中央/镇府才算真正控住。名义上「属河东」不等于税和兵听命。

## 2. Tick：不要每人每步做完整决策

CK3 的核心不是每秒重思考，而是：

1. 世界持续推进；
2. 事件改变局势；
3. 相关人物被唤醒；
4. 人物重估计划；
5. 计划分阶段执行。

技术选型已要求：固定逻辑步长；远离关注范围聚合计算；到达事件点才唤醒；倍率只改调度频率、不改规则语义；暂停时停止一切改世界的逻辑。本稿把这套落到五代十国。

### 2.1 玩家可见时钟 vs 内部 Tick

| 层 | 谁看见 | 处理什么 |
|----|--------|----------|
| **日** | 玩家主时钟 | 方针推进、消息送达、探子耗时、双时间戳、日结 |
| **日内分步** | 仅模拟层 | 军队移动、围城、使者到达、粮耗、战斗推进 |
| **旬**（10 日） | 仅模拟层 | 重要人物定期重估、士气、叛军扩散、谈判进度、短期军事决心 |
| **月** | 仅模拟层 | 军饷与财政结算（拖饷在此产生）、任命、派系、战争/纳贡/臣服 |
| **季 / 年** | 后置 | 整编、人口、合法性、继承风险、地区结构变化 |

玩家 UI 只表现 **日** 与暂停态（挂机慢走 / 自愿停 / 危机强制停）。旬月季年不得做成第二个「回合制界面」，也不得向玩家泄露「某 NPC 本旬 AI 评分」。

日内分步的粒度由主程定（时辰或固定分钟步均可）；玩法只要求：

- 命令发出 ≠ 当天结算；
- 使者 / 探子 / 军报有旅行时间；
- 暂停必须冻结这些步。

### 2.2 与日循环 B 的咬合

```text
设常驻方针 → 日 Tick 慢走（挂机）
        → 模拟层推进日内分步 / 旬 / 月
        → 生成 Hidden 事件
        → 按玩家认知裁剪
        → 异常 / 到期回报进消息流
        → 已知区达精确门槛 → 危机强制暂停
```

- 部下按方针自动干活 = 治下人物/集团在日 Tick 上执行已授权计划。
- 消息流只推异常 = 多数 Tick 结果被聚合或静默，只有越过「异常门槛」的才投递。
- 危机强制停 = 玩法文档四条门槛同时满足（对象已知 + 有证据 + 有期限 + 有得应对）；事态升级重新触发；迷雾外最多「某方向久无信」。
- 脏情报可制造假危机或掩盖真危机：AI 的 Hidden 行动经过情报污染后，玩家可能看到错的危机。

### 2.3 定时扫描 + 事件唤醒

纯扫描所有角色会慢，也会机械。用两种机制。

**定时扫描（每旬）** 只覆盖：

- 所有统治者 / 重要军阀
- 玩家治下四集团的代表人物
- 高危继承人
- 处于战争中的人物
- 严重不满的集团

**事件立即唤醒** 相关人物：

- 皇帝 / 节度使死亡
- 军镇易主、政变、大败、首都或治所失陷
- 粮道中断、亲军/牙军叛变
- 继承人被废、邻镇称王/称帝（后置）
- 重要盟友被灭、重大灾荒
- 朝廷征召、其他藩镇倒戈
- 玩家方针切换、玩家对某集团持续打压或持续偏信（世界把方针读成态度）

例：

```text
节度使死亡
→ 唤醒：继承人、亲军将领、副使/判官、相邻藩镇、朝廷、婚姻盟友、可能夺地者
```

平稳期不浪费计算；关键节点政局可以在数日 Tick 内洗牌。

### 2.4 计算与执行分离

每个逻辑步建议：

```text
A. 所有被唤醒人物观察自己的认知世界
B. 生成意图（尚未改世界）
C. 解决冲突（同一城、同一支牙军、同一道诏令）
D. 应用结果 → 调度后续事件 / 消息 / 危机门槛
```

禁止「谁先被扫到谁先得手」。暂停时 A–D 全部停。

## 3. 人物 AI 四层（优先级从上到下）

不要一个大函数直接决定「攻打某城」。分层。玩家治下执行人只用第 1 层 + 方针约束；邻镇统治者走全四层。

### 第一层：生存与权力安全（最高）

先判断：

- 自己会不会被杀 / 被废
- 军队会不会叛
- 家族会不会被清洗
- 城能不能守、继承人在不在
- 亲军是否可靠、军饷是否拖欠

五代应有较强的短期生存偏好：朝廷护不住你时，先保部曲和家族；没有亲军的主君，不会轻易清洗大将。

```text
安全评分 =
军队忠诚（集团层）
+ 治所防御
+ 盟友可援（按其认知）
+ 继承稳定
+ 财政储备
- 内部派系敌意
- 外部威胁（按其认知）
- 个人疾病
- 军饷拖欠
```

低于阈值进入 **危机模式**：暂停长期目标，优先求援、交质、迁治、赦免、让位、出逃、投降、发动政变（后几项后置）。

玩家侧对应：治下安全崩溃应先表现为异常消息和已知区危机，而不是突然 Game Over。失败条件以玩法文档为准（主公失位 / 治所失陷 / 治下过半州实际控制丢失；耳目尽失是严重状态不是失败；「朝廷削权」仅用于可服从朝廷的剧本）。

### 第二层：权力扩张

安全之后才评估：

- 邻近州府 / 关隘 / 粮道 / 盐场
- 能否控制或影响朝廷名义
- 更高官职、消灭竞争者、整合地方

不要只算领土面积，要算可治理性：

```text
目标价值 =
战略位置 + 财政 + 粮食 + 人口 + 声望 + 对敌削弱
- 进攻成本 - 后勤距离 - 占领后叛乱 - 第三方干预
```

军阀优先争夺都城、关隘、粮道、盐场、富庶区和现成兵源，而不是「最近的邻格」。

首版邻镇 AI 的扩张应表现为 **边压、试探、截粮、诱降、请朝廷下诏**，不要开局就全面战争。潞州边压读点是验收锚，不是全图征战。

### 第三层：合法性与名分

不能只用好感解释政治。人物还要考虑：

- 称帝/称王资格、禅让文书、旧都、士人支持、藩镇承认、宗室血统
- 能否把敌人定义为叛逆，自己定义为奉诏

政治姿态（NPC 内部状态，不做成玩家可见的阵营条）：

| 姿态 | 要做什么 |
|------|----------|
| 奉朝廷 | 讨叛、要任命、借中央名义扩张 |
| 挟天子 | 控诏令、索官爵和贡赋 |
| 观望 | 两面下注、纳贡、保存军力 |
| 自立 | 截税、建自己的财军、称王（后置） |
| 复辟 | 拥立旧朝（后置） |

首版邻镇默认应大量落在 **观望 / 奉朝廷（口头）/ 边压**，少见自立。

### 第四层：性格与关系（修正项，不是战略本身）

| 性格 | 修正 |
|------|------|
| 猜忌 | 更重人质、监控、清洗；降低信任 |
| 勇猛 | 更倾向主动进攻、亲自领兵 |
| 谨慎 | 提高撤退阈值，更偏好联盟和观望 |
| 贪婪 | 重盐场、商税、截赋、掠夺 |
| 宽仁 | 降低屠城与清洗，提高招抚 |
| 果断 | 更快接受高风险方案 |
| 保守 | 维持现状和旧秩序 |
| 野心 | 提高夺权权重（仍受第一层安全约束） |
| 多疑 | 更容易把失败归因于谋反 |
| 崇文 | 重视士人与文书名义 |

关系至少拆：

```text
个人好感
政治信任
军事依赖
利益一致
血缘与婚姻
历史仇恨
集团关系
```

「喜欢一个人」≠「愿意把牙军交给他」。这些全部是 Hidden / 认知层；UI 只允许通过消息语气、拖延、拒令、偏报来感觉到，禁止做成忠诚条。

## 4. Utility：候选行动打分

实现建议用「候选行动 + 评分」，不要巨型决策树。

```text
行动评分 =
基础收益
+ 性格修正
+ 关系修正
+ 当前危机修正
+ 目标战略价值
+ 集团支持
+ 成功概率（基于认知，不是全知）
- 资源成本
- 失败惩罚
- 长期反噬
- 名分损失
```

### 行动类型（按阶段解锁）

**治下 / 内政（首版就要能驱动挂机）**

- 执行或扭曲玩家方针
- 催粮、截赋、赈济、修缮城防
- 索饷、安抚豪强、拖延王命
- 任命/排挤（后置）

**军事（首版：边压、调防、出征的 NPC 对应物）**

- 压迫边境、截粮道、围点（玩家侧可能只看到失联或弱信号）
- 撤军、护粮、招降、劫掠后方

**政治**

- 联姻、交质、结盟、纳贡、乞援
- 请朝廷加官或下诏
- 拥立 / 废立 / 称王（后置）

**阴谋**

- 收买将领、煽动牙军、伪造文书、分化派系
- 刺杀（后置，慎用）

例：评估「发动政变」（后置内容，公式先留）

```text
政变评分 =
亲军支持 × 2
+ 对主君不满
+ 个人野心
+ 朝廷/镇府虚弱
+ 成功后收益
- 禁军或对手亲军
- 其他藩镇干预
- 失败被清洗
- 士人与名分反对
```

玩家 **禁止** 看到这些分数。能看到的是：来源、日戳、主张、完整度、矛盾、执行快慢。

## 5. 计划：短 / 中 / 长，不要左右横跳

| 层 | 时长 | 例子 | 何时重算 |
|----|------|------|----------|
| 短期行动 | 数日–数月 | 调兵、谈判、围点、派探子、赈灾、镇压 | 行动结束、失败、被更高优先级打断 |
| 中期计划 | 数月–数年 | 控某军镇、建亲军、削某派系、边压某方向 | 战争结果大变、集团破裂、财军崩溃 |
| 长期目标 | 数年+ | 保住家族与镇、控制某粮道、维持名义上的奉朝 | 统治者死亡、治所易手、继承改变、新强权出现 |

玩家的常驻方针 ≈ 玩家强加给治下的中期计划。方针轻摩擦：换了很快生效，旧任务不会瞬间蒸发——对应「短期行动继续收尾，中期计划改向」。

NPC 不得每月随机换长期目标。只有第 2.3 节的唤醒条件才允许重算长期层。

## 6. 五代十国必须重点模拟的系统

### 6.1 牙军和亲军

核心资源之一。重要军阀应区分：

| 军队 | 忠诚对象 |
|------|----------|
| 亲军 | 将领本人 |
| 牙军 | 军镇集团利益（饷、编制、家属） |
| 地方驻军 | 州府与地方精英 |
| 临时征召 | 弱、易散 |
| 降军 | 低、受待遇左右 |
| 外援 | 派遣者 |

军队不只看士气，还看：军饷、将领是否被换、家属是否在控制区、战利品、是否怕被清洗、愿不愿意随主帅流亡。

玩家侧表现：拖饷 → 牙军异常消息 → 已知区拒令/兵变危机。不要做一条「牙军忠诚 65」HUD。

### 6.2 忠诚不是单一数值

内部至少拆：

```text
个人忠诚     对某个主君
集团忠诚     对牙军、士人、地方
职位依附     对当前官位
利益一致     继续合作是否有利
恐惧         背叛的惩罚有多大
```

一个将领可以：对节度使个人忠诚低、对朝廷名义仍有一点认同、对自己的牙军极高忠诚、因家人在治所而暂时服从。这样才能出现「表面奉诏、实际观望」。

UI 不做全局忠诚条站队，与玩法文档一致。

### 6.3 继承与政变（第二阶段）

五代经常不是平稳继承。系统应能表达：血缘、军队拥立、文官拥立、兄弟争位、养子、遗诏争议、外藩入京、禅让、废帝、出逃。

继承 AI 要在主君病重时就开始拉拢，而不是死亡后才触发。首版若只做「主君突然死亡 → 统治链条检查」，可以；完整争位后置。

### 6.4 名义控制 vs 实际控制

一个州可以：

- 名义属河东；
- 税被地方截留；
- 中央/镇府任命的官无法赴任；
- 兵听牙将不听节度使。

失败条件里的「治下过半州实际控制丢失」（及可服从朝廷剧本里的「朝廷削权」）应落在这组控制值上，而不是只扣一个「独立度」。

### 6.5 南北差异（后置修正，不当性格锁死）

| | 北方 | 南方 |
|--|------|------|
| 环境 | 军事竞争强、政权短、边骑与粮耗重 | 城市商业水运、更愿纳贡结盟守成 |
| 权重 | 提高军事、亲军、政变 | 提高财政、外交、贸易、稳定 |

开局河东 908 在北方。南方权重表后置，避免首版就模拟十国全图。

## 7. 信息不完全（AI 也有雾）

若 NPC 全知、玩家有雾，挂机会变成「瞎子对明眼人」，知情权反 CK3 会不公平。

### 7.1 每个行动者一份认知

```text
Hidden 真值     模拟层
认知状态        每个重要人物一份（含玩家）
展示状态        仅玩家 UI
```

NPC 决策只读自己的认知：已知、推测、错误、延迟。使者可能被截；兵力只能估算；远方粮储未知；谣言可导致错误行动。

NPC 的认知可以比玩家 UI 更密（本地耳目、无「玩家界面」限制），但 **不是全图真值**。邻镇不应精确知道河东金库和玩家探子名单。

### 7.2 投递给玩家时再裁一次

```text
NPC 行动结算
→ Hidden 事件
→ 按玩家已知范围 / 来源 / 延迟 / 污染生成消息
→ 迷雾外：弱信号或静默
→ 已知区达精确门槛：危机强制停
```

探子结果只进消息流、不自动弹出征——这条对 NPC 对玩家的行动同样适用：即使 Hidden 里敌军已开拔，玩家没达到精确门槛就不能弹「敌军正在围 X」。

### 7.3 失败要有连续后果

一次战败（或一次拖饷、一次假报）不应只减兵力：

```text
战败或拖饷
→ 军心下降
→ 军饷压力
→ 牙军不满
→ 地方豪强观望
→ 盟友加码
→ 继承人/副使开始另谋
→ 敌方趁机策反
```

玩家应能在后续消息里认出这条链，而不是只看到「系统判定失败」。

## 8. 建议的月度（或等价低频）流程

挂机时，日 Tick 内部按批次跑；重要人物的完整 AI 不必每日全量。

```text
1. 推进时间（尊重暂停 / 倍率）
2. 健康、旅途、死亡、使者到达
3. 军队移动、战斗、围城
4. 粮、饷、税
5. 地方控制值与集团不满
6. 已触发事件
7. 唤醒受影响人物
8. 更新短期行动（治下先套玩家方针）
9. 必要时重估中长期计划
10. 外交 / 任命 / 阴谋意图入队
11. 冲突解决并应用
12. 生成 Hidden 事件 → 裁剪为消息 / 危机 / 静默
13. 记录可重放状态（种子 + 规则版本 + 命令序列）
```

LLM 若生成文案：只替换展示文本，不得在此流程里改评分或推进时间。

## 9. 完整决策例（邻镇，首版边压）

（通用示例，非 908 实际演员：908 潞州方向是后梁围城军。）

假设某邻镇节度使：威望中等，亲军尚可，财政紧，朝廷远，河东最近在「稳边」与「积粮」间切换，其探子只带回「河东某州调防、商路少车」之类旧报。

认知：河东可能在收缩，但不确定是否空。

候选（示意）：

```text
扩编亲军        高
与邻镇联姻/交质  高
截部分商路试探   中高
请朝廷加官       中
进攻已知弱州     低（安全层未过、情报不足）
公开称王         极低
```

于是 AI 先扩军、交质、在边州制造玩家可能感知为「某方向久无信 / 商路异常」的压力，而不是因为「野心高」就宣战。

若随后河东牙军索饷消息外泄、其使者确认某城失联，再唤醒、重估、把「进攻」抬上去。玩家侧：可能先收到弱信号，直到已知区达精确门槛才强制停。

治下执行人的例子更简单：方针=积粮 → 短期行动催粮；牙军拖饷过高则第一层打断，生成拒令/索饷异常，而不是继续完美执行积粮。

## 10. 分阶段落地（不开本文件 feature）

本稿是骨架，不开启 ai-sdlc 版本、不改 Godot。实施时另开 Intent。

### 第一阶段（对齐河东 908 最小闭环）

- 日 Tick + 日内分步 + 暂停三态（自愿 / 挂机 / 危机强制）
- 人物、政权、州府的最小字段
- 治下四集团代表人物：按方针执行，带效率 / 偏差 / 政治代价
- 己方人物对令的反应：照办 / 拖延 / 阳奉阴违 / 托病 / 拒令（首版人事令召见 / 赏赐 / 任免 / 拘捕依赖此项，见 `2026-11-01-first-ship-orders.md`）
- 908 内部演员的最小意图：李克宁一线的「政变意图」（可有可无，按种子）、告密者（可有可无）
- 外部演员：后梁围潞诸将（围城 / 诱降己方部将）；不做称帝
- 主公作为执行人：所在地影响命令与消息路程
- 财政粮饷、军队移动与战斗的最小结算；**被围城存粮单独计算**（镇库粮进不了围城，须靠输粮令）
- Hidden → 认知裁剪 → 消息 / 弱信号 / 危机门槛
- 死亡仅作统治链条检查（耳目、兵变、架空）

验收应对齐玩法文档那条最小体验：选方针 → 推进若干日 → 不完整消息 → 已知区可暂停危机 → 出征或调防 → 延迟回声 → 看见后果。

### 第二阶段

- 牙军/亲军分账
- 忠诚分层（仍不进 UI 条）
- 政变完整链条（第一阶段只有意图 + 拘捕 / 告密应对）；拒令后果深化
- 事件唤醒补全
- 名义/实际控制分离
- 邻镇中期计划（截粮道、请诏；诱降已由后梁在第一阶段先做）

### 第三阶段

- 朝廷合法性、奉诏讨伐、傀儡
- 错误情报进入 NPC 认知（不只进入玩家消息）
- 探子与 NPC 耳目对等
- 地区差异

### 第四阶段

- 历史人物个性化长期目标
- 复杂阴谋、继承大战
- 动态称王称帝与王朝形成
- 南方十国权重

## 11. 给主程的接口暗示（无代码）

与技术选型中的 Simulation Core / PerceivedState 对齐：

- `WorldClock`：日为玩家时钟；内部固定步；倍率不改语义；暂停切断一切写世界。
- 人物 AI 是规则层模块，输入为该人物的认知快照 + 集团状态 + 当前计划，输出为意图队列，不直接写 UI。
- 治下执行：方针是约束，不是脚本；执行人可以拖延、偏执行、另报。
- 消息生成只读「玩家认知 + 来源规则」，禁止读 Hidden 真值拼文案。
- 存档必须包含：世界时间、人物计划、集团状态、每人认知、事件队列、方针生效时间。展示态（已读、缩放）不得绕过迷雾。
- 确定性：开局种子 + 规则版本 + 玩家命令序列应可重放 AI 结果（AI 内部随机走同一随机流）。

## 12. 设计原则（五句）

1. **人物先求生存，再求扩张，最后追求名分。**
2. **军队忠于具体集团，不天然忠于「国家」或玩家 HUD。**
3. **名义控制和实际控制必须分离。**
4. **关键事件唤醒 AI，平时用低频 Tick；玩家日循环仍是 B。**
5. **五代十国的味道不是把战争频率调高，而是一次拖饷、一封真假难辨的文书、一个继承人的空窗，都能在数日 Tick 内重洗权力。**

再加一条本仓特有的：

6. **AI 可以在 Hidden 里很忙；玩家知情权必须反 CK3。**
