> 2026-11-01 补拍板：多剧本；首剧本「河东 908」玩家为李存勖、后梁为敌对伪朝；时间尺度；不设额度的约束逻辑；方针单选；危机强制停门槛；首版命令集。见文末备忘。
> 2026-11-02 补拍板：**自由游戏**，无胜利条件、无阶段目标、无「幕」；只设失败条件，失败即结束。

## 一句话

五代十国背景下的有雾 CK3 简化版：你是一镇节度使，在不完整、可能过时、可能带立场甚至互相打架的情报里，做单机策略生存和政治/信息博弈。

**壳可以更像 CK3，知情权必须反 CK3。**

## 剧本

- **多剧本**：未来可选不同年份、不同节度使。剧本 = 年份 + 玩家人物 + 治下州 + 开局人物/集团状态 + 外部政权关系（含「朝廷」是谁、是否奉其正朔）。规则层通用，剧本只给初始状态。
- 剧本里的史实事件只能做成**初始状态 + 压力规则**；禁止写死「第 N 天必出某剧情」。

### 首剧本「河东 908」

- 玩家：**李存勖**。天祐五年（908）正月李克用卒，新嗣晋王、河东节度使，年轻，被义儿老将看轻。
- 疆域：史料称「河东九州」；种子约 12 州（含被围的潞州/昭义），具体州表待核。
- **朝廷**：唐已亡（907 朱温篡唐建梁）；河东不奉梁正朔、仍用天祐年号。
  - **后梁 = 敌对伪朝**：主要手段是对你的部将、地方**诱降**（许官、许地），并在潞州筑夹寨长围。
  - **唐名分 = 资源**（合法性）；张承业（自称唐河东监军使）是名分守护者。
- 开局压力（初始状态，不是剧本）：
  - 李克宁掌兵、野心高，李存颢等义儿在旁怂恿「兄终弟及」；
  - 潞州被围、城中粮在倒数（李嗣昭守）；
  - 援军主将周德威与李嗣昭不睦。
  - 告密者不一定存在，政变不一定发生，夹寨不一定被破。
- 四集团对位：牙军/义儿军（李克宁、李存颢）· 监军/文官（张承业、卢质）· 边镇将领（李嗣昭、周德威）· 地方（泛化）。

## 玩家与目标

- **自由游戏**（同 CK3）：没有胜利条件、没有阶段目标、没有「幕」；玩家自己决定要做什么，只要不失败就一直玩下去。
- 玩家自然面对的是：迷雾里保住镇、稳住钱粮兵与人事、扛住边压和内部试探——不是一统天下。
- **失败即结束**。失败条件须可明确判定（不靠任何数值条）：
  1. **主公失位**：被杀、被拘、被废（含政变 / 兵变成功）；
  2. **治所失陷**：治所（908：晋阳）被攻破或被献出；
  3. **镇被架空**：治下过半州（908 种子 12 州，即 6 州及以上）实际控制丢失（附敌、被夺、拒不受节制）。
  - 单个部将附敌、单州失陷不算失败，只计入第 3 条。
  - 可服从朝廷的剧本可另加「朝廷削权」；908 不用。
- **耳目尽失不是失败**，是严重状态：各方向都久无信、消息只剩弱信号。看不见本身就是惩罚。

## 日循环（已定 · 方案 B）

对照 CK3 / 三国志14 后选型：**偏 CK3 的暂停循环，砍通视；不采用 14 式每日早朝刷奏折为主干。**

1. **平时时间慢走**：部下按你设的「常驻方针」自动干活。
2. **消息流只推异常**与到期阴谋/探子回报；点开才暂停。
3. **危机强制暂停**（门槛见下）→ 只能在**已知情报范围内**选目标并确认下令。危机强制停**本身不可关**；普通提示可关；触发时须说明理由；玩家可选继续挂机。
4. **主动动作不设额度限制**（约束逻辑见「下令与政治」）。
5. **玩家可随时自愿暂停**挂机或日推进；自愿停与危机强制停是两回事。

地图是证据板，不是每天第一站；迷雾外无精确警报（最多「某方向久无信」）。

### 时间尺度

| 层 | 1 倍速约合 | 用途 |
|----|-----------|------|
| **日**（玩家主时钟） | ~10 秒（2 倍速 5 秒、3 倍速 2 秒） | 消息送达、命令在途、日结 |
| **旬**（仅模拟层） | ~1.5 分钟 | NPC 定期重估 |
| **月** | ~5 分钟挂机 | 军饷、财政结算（拖饷 → 牙军异常） |
| **季** | — | 考课、税赋、长期目标重估 |

**消息密度目标**（1 倍速，数值可调，比例为准）：

| 项 | 目标 |
|----|------|
| 异常消息 | 每游戏日 0.3–0.6 条（每月约 10–18 条） |
| 危机强制停 | 每游戏月 3–5 次 |
| 最长静默 | 连续不超过 5 个游戏日无任何异常消息 |

按此密度，1 个游戏月（含暂停读消息、处理危机、筹划）约 **20 分钟**，仅作测试估算；时长由密度推出，不为凑时长加密消息。

### 常驻方针（单选，参 CK3 专精）

- 全局**单选**一个方针；切换**轻摩擦**：很快生效，旧任务收尾而非瞬间蒸发；不设长硬冷却。
- 首版 5 个：**稳边 / 积粮 / 盯某邻（带一个目标参数）/ 广布耳目 / 收拢人心**。
- 每个方针至少反馈三样：消息流里读得到、地图上看得到、被人物/外部势力读成态度。不能只有正面收益。
- 每个方针 = **一项收益 + 一项资源代价 + 一种两面都有的读法**：

| 方针 | 收益 | 代价 | 被怎么读（两面都有） |
|------|------|------|-------------------|
| 稳边 | 边州回报准时，守城更稳 | 内地驻军被抽薄 | 边将安心；义儿军读成「主公怕梁」 |
| 积粮 | 镇库粮增加 | 地方怨气上升；商路减少，消息变少 | 牙军若同时欠饷更恼（有粮不发饷） |
| 盯某邻 | 该方向消息更多、更快 | 其他方向更静，易久无信 | 对方读成备战，可能提前动作 |
| 广布耳目 | 各方向消息都变多 | 耗钱；消息更浅、矛盾更多 | 各集团读成猜忌，义儿军反应最大 |
| 收拢人心 | 集团不满上升变慢 | 耗钱帛；军务推进变慢 | 有人读成宽厚、有人读成示弱（本局真实读法为 Hidden） |

- **方针不直接解决具体危机**：它决定底色，解决问题靠令。
- **被围城的存粮单独计算**：镇库粮再多也进不了围城，只能靠输粮令破围送入（908：「积粮」不等于救潞州）。

### 危机强制停门槛

四条**同时**满足才强制停：

1. **对象已知**：己方据点 / 己方人物 / 已探明州。
2. **有证据**：一条直接来源（己方驻军、主官亲报）**或**两条独立来源；同源转述不算独立。
3. **有期限**：不处理会在数日内恶化或不可逆。
4. **有得应对**：至少存在一个玩家现在能下的令。召回 / 改令恒可下，故执行人全数离岗不会让危机「不停」。

防刷屏：

- 同一对象在危机未解前只算一次，后续相关消息并入；**事态升级（如索饷 → 哗变）重新触发强制停**。
- 敌方伪造危机须实际执行「伪造文书 / 收买」类行动（有成本、有被识破风险）。
- 暂停卡列出命中了哪几条、证据来自哪里——即「须说明理由」。

首版危机清单：城失联（超约定回报期算一条己方驿传直接来源，另需第二条独立异常）、据点遭攻（驻军亲报）、拒令/索饷（主官亲报）、阴谋暴露（告密者亲报）。

### 与迷雾咬合

- 迷雾外：不知道的战争不弹「敌军正在围 X」精确卡。
- 脏情报可制造假危机或掩盖真危机（伪造须付成本，见上）。
- 下令仍是「选目标 → 确认」；确认摘要只用当前可知信息。

### 风险（开发时盯）

- 自动化过强 → 玩家觉得自己没决定；方针要可感、可改、会被世界读成态度。
- 别滑回「盯地图点部队」；危机外少给精确军情。

## 信息与探子

- 知道：治下钱粮兵、消息卡来源/日戳/主张。
- 不知道：邻境真兵力金库、忠诚条、谁在撒谎。界面**禁止「可信度」分/条/文案**；用不替玩家判真假的「来源 / 完整度 / 矛盾」等可解释线索；不给「建议先打谁」。「完整度」只能列出缺了哪些项（例如缺兵力、缺日戳），禁止做成数字、进度条或任何可排序的分数。
- 消息**双时间戳**：事件发生时间 vs 送达时间。
- 探子：可招募；候选人**随机生成**（不同能力/特点，**禁年龄**）；花钱；可能暴露；情报可假（空/偏/旧），永不等于真相；结果**只进消息流、不自动弹出征**。
- 招募候选人：一次默认 **2–4** 人，可过期离场。
- 同一方向重复派探：暴露递增、回报更易被污染（收益递减），迷雾不可被钱买穿。
- 探子暴露：允许**局部补救**（换渠道、撤离/封口费、暂停该地区等）；**禁止一键全局洗白**。

## 下令与政治

- **首版命令集**（细则见 `design/quick-specs/2026-11-01-first-ship-orders.md`）：
  - P0（12）：军事 出征 / 调防 / 召回 / 输粮；人事 召见 / 赏赐 / 任免 / 拘捕；情报 招募探子 / 派探 / 查证 / 补救。
  - P1（3）：安抚、加征、开仓赈济。
  - 后置：遣使、诈降 / 反间、通用明令 / 密令开关。
- **目标**：军事令目标是地点（州 / 关），人事令目标是人物或集团；**任何令都不能以敌军单位为目标**。未探明的州仍可下令（迷雾不是门禁）。失败只说玩家能理解的原因。
- **受令方可以不照办**（拖延 / 阳奉阴违 / 托病 / 拒令）；不照办本身就是情报，拒令危机主要由此长出。
- **不设额度的约束逻辑**：不限次数、不设行动点、不设冷却；每个动作必须答得出五问——
  1. **派了谁**：将领/探子/文官同一时间只办一件事，派出即离岗，空缺本身是风险（危机排序压力主来源）。**主公本人也是执行人**（坐镇 / 亲征 / 亲巡 / 设宴只能择一）。驿传送令不占人物；
  2. **要多久**：有路程与延迟；命令与消息共用驿传，**从主公所在地起算**；
  3. **花了什么**：钱粮、封口费等；
  4. **谁会怎么读**：每道令都被各集团读成态度（常压牙军 → 索饷；频繁调防 → 被读成备战）；确认摘要只列知情范围，不预测反应；
  5. **暴露了什么**：同向重复查证暴露递增；拘捕有准备期泄露风险。
  答不出「派了谁」的动作，要么不该存在，要么补上执行人。**明文例外：换方针**（方针是施政口径，由四集团代表日常执行；只答「要多久」与「谁会怎么读」）。
- 博弈：牙军、监军/文官、地方、边镇，以及剧本中的外部政权（908：后梁诱降）；NPC 会读你常信谁、常压谁。不做全局忠诚条站队。

## 交互壳与故事

- 默认壳：地图司令部 + 侧边情报消息流（不要案头卷宗当主壳）。
- 故事：剧本开局状态 + 压力规则涌现；禁止写死「第 N 天必出某剧情」。

## 明确不抄

**CK3**：邻国兵力/性格通视；无探子精确警报；军师式最优解提示。  
**三国志14**：全图见敌军细节；高智力军师≈标准答案；情报一览点开全势力数据；军情只加成不藏信息。

### 2026-11-01 · 首版命令集

7. **命令集**：P0 12 道（出征 / 调防 / 召回 / 输粮 / 召见 / 赏赐 / 任免 / 拘捕 / 招募探子 / 派探 / 查证 / 补救），P1 3 道（安抚 / 加征 / 开仓赈济）；遣使、诈降 / 反间后置。

### 2026-11-02 · 自由游戏与失败条件

12. **自由游戏**：无胜利条件、无阶段目标、无「幕」；失败即结束。
13. **失败条件**：主公失位 / 治所失陷 / 治下过半州实际控制丢失。
14. **耳目尽失**改为严重状态，不是失败。
15. **节奏以消息密度为准**：异常消息每日 0.3–0.6 条、危机强制停每月 3–5 次、最长静默不超过 5 日；1 游戏月约 20 分钟仅作估算。
16. **方针表**：每个方针一项收益 + 一项代价 + 一种两面读法；方针不直接解决具体危机；被围城存粮单独计算。
