# 节度使 · 玩法口径（新仓）

> 2026-10-30 拍板。日循环：**B 议会挂机 + 危机打断**（明确不采用旧仓「看图→读流→点卡下令→等回声」）。同日补硬定：主动动作**不设额度**、方针**轻摩擦**、危机强制停**不可关**、探子招募 **2–4**、暴露**局部补救**。

## 一句话

五代十国背景下的有雾 CK3 简化版：你是河东节度使，在不完整、可能过时、可能带立场甚至互相打架的情报里，做单机策略生存和政治/信息博弈。

**壳可以更像 CK3，知情权必须反 CK3。**

## 玩家与目标

- 你是河东节度使；开局「河东 908」种子（约 12 州 + 潞州边压读点）。
- 目标：迷雾里保住镇、稳住钱粮兵与人事、扛住边压和内部试探——不是一统天下。
- 输掉：统治链条断掉（耳目尽失、兵变、被架空、朝廷削权、被吞并等）。完整「赢」终局暂不钉死。

## 日循环（已定 · 方案 B）

对照 CK3 / 三国志14 后选型：**偏 CK3 的暂停循环，砍通视；不采用 14 式每日早朝刷奏折为主干。**

1. **平时时间慢走**：部下按你设的「常驻方针」自动干活（如稳边 / 积粮 / 盯某邻）。
2. **消息流只推异常**与到期阴谋/探子回报；点开才暂停。
3. **危机强制暂停**（敌军出现在已知区、城失联、阴谋暴露等）→ 只能在**已知情报范围内**选目标并确认下令。危机强制停**本身不可关**；普通提示可关；触发时须说明理由；玩家可选继续挂机。
4. **主动动作不设额度限制**：暂停、读消息本来就不计；主动下令、情报采购、换方针也不限额（仍不鼓励天天点兵刷图，靠摩擦与成本约束，不靠额度）。
5. **玩家可随时自愿暂停**挂机或日推进；自愿停与危机强制停是两回事。

地图是证据板，不是每天第一站；迷雾外无精确警报（最多「某方向久无信」）。已知区须达精确门槛才强制停；迷雾外仅弱信号。

### 与迷雾咬合

- 迷雾外：不知道的战争不弹「敌军正在围 X」精确卡。
- 脏情报可制造假危机或掩盖真危机。
- 下令仍是「选目标 → 确认」；确认摘要只用当前可知信息。

### 风险（开发时盯）

- 自动化过强 → 玩家觉得自己没决定；方针要可感、可改、会被世界读成态度。
- 别滑回「盯地图点部队」；危机外少给精确军情。

## 信息与探子

- 知道：治下钱粮兵、消息卡来源/日戳/主张。
- 不知道：邻境真兵力金库、忠诚条、谁在撒谎。界面**禁止「可信度」分/条/文案**；用不替玩家判真假的「来源 / 完整度 / 矛盾」等可解释线索；不给「建议先打谁」。
- 消息**双时间戳**：事件发生时间 vs 送达时间。
- 探子：可招募；候选人**随机生成**（不同能力/特点，**禁年龄**）；花钱；可能暴露；情报可假（空/偏/旧），永不等于真相；结果**只进消息流、不自动弹出征**。
- 招募候选人：一次默认 **2–4** 人，可过期离场。
- 探子暴露：允许**局部补救**（换渠道、撤离/封口费、暂停该地区等）；**禁止一键全局洗白**。

## 下令与政治

- 首版地图令：出征、调防；主动下令**不设额度**。
- 未知邻境仍允许下令（迷雾不是门禁）；失败只说玩家能理解的原因。
- 博弈：牙军、监军/文官、地方、边镇；NPC 会读你常信谁、常压谁。不做全局忠诚条站队。
- **方针切换摩擦：轻**——换了很快生效，短时间有一点点换档别扭（旧任务不会瞬间蒸发）；不设长硬冷却。

## 交互壳与故事

- 默认壳：地图司令部 + 侧边情报消息流（不要案头卷宗当主壳）。
- 故事：开局种子 + 压力规则涌现；禁止写死「第 N 天必出某剧情」。

## 明确不抄

**CK3**：邻国兵力/性格通视；无探子精确警报；军师式最优解提示。  
**三国志14**：全图见敌军细节；高智力军师≈标准答案；情报一览点开全势力数据；军情只加成不藏信息。
